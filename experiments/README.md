# Experiment configurations

Store small, versioned experiment configurations here after the baseline audit.
The format and schema are not finalized yet.

Each configuration should identify scales, selected queries, seeds/parameters,
warmups, measured trials, query order, concurrency, timeout, threads, memory limit,
and cache policy. Reference the pinned baseline and generator. Keep secrets and
machine-specific absolute paths out of shared configurations.

Final scales must follow capacity measurements; no final scale set is selected.
